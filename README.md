# 民泊管理用 在室・入退室検知システム

ローカルの防犯カメラ（Tapo C200）の映像とAI（YOLO）を活用し、民泊におけるゲストの在室状況（在室・不在、チェックイン・アウト、外出・帰宅）をローカル環境で高精度に自動判定するシステムです。

---

## 1. 現在の状況 (実装済みの機能)

現在、ローカルPC上で動作する2つのコア判定アルゴリズムが実装されています。

### ① YOLOによる入退室判定 (ゲート横切り検出)
- **ファイル:** `src/yolo/rule_detector.py`, `src/yolo/evaluate_rules.py`
- **概要:** YOLOv11による人物のトラッキング座標を用い、玄関のドアゾーン（$X \ge 1500$, $Y \le 350$ のエリア）をどの方向に横切ったかで「入室 (entry)」「退出 (exit)」を判定します。
- **成果:** 
  - テストデータを用いた検証で **全体正解率 93.3%** を達成。
  - 特に `entry` と `exit` の **適合率 (Precision) は 100%** となり、ただ前を横切っただけの動き（ノイズ）による誤検知を完全に排除しています。

### ② YOLO-Worldによる「靴・荷物・人」のローカル検出
- **ファイル:** `detect_shoes_yolo.py`
- **概要:** 事前学習済みのオープンボキャブラリーモデル「YOLO-World」を活用し、追加学習や外部クラウドAPIを一切使わずに、玄関のたたきにある「靴、カバン、スーツケース、人」をローカルで検出します。
- **成果:**
  - 検出された物体の位置を四角（バウンディングボックス）で囲んだ動画・静止画の出力に対応。
  - カメラの首振り（アングル変更）に対応するため、画面の上側（スリッパラックなどの誤検知源）を除外する「Y軸制限フィルタ（$Y \ge 300$）」を搭載。
  - 靴が見切れたアングルでも、スーツケースや人物自体をまとめて検知することで、頑健に在室（帰宅）を捉えられます。

## 2. 今後やろうとしている取り組み (ロードマップ)

ローカルPC（Linux Desktop環境）の強みを活かし、実運用に向けて以下の機能拡張を計画しています。

### ① ローカルPCでの常時録画 (FFmpegレコーダー化)
- **目的:** 運用の初期フェーズにおいて、評価・チューニング用の実際のゲストの行動データを蓄積する。
- **計画:** 
  - FFmpegを用いて、カメラから映像を直接（再エンコードなしの超低負荷で）1時間ごとに分割して常時録画（`.mp4`）します。
  - ゲストのプライバシー保護と規約厳守のため、音声データは録音から完全に除外します (`-an` オプション)。
  - 250GBの空き容量を活用して約10日分の動画を常にストックし、古いファイルは自動でスクリプト削除（クリーンアップ）する仕組みを構築します。

### ② 複合センサーによる在室判定 (センサーフュージョン)
- **目的:** 「靴を靴箱にすべてしまわれ、カメラから見えなくなった」際にも、誤って「不在」と判定されるのを防ぐ。
- **計画:**
  - カメラとは別に、客室内に **赤外線センサー（PIR）** および **ミリ波レーダー（人感存在センサー）** を設置します。
  - ローカルPCにすべてのデータ（カメラ ＋ ミリ波 ＋ 赤外線）を集約し、以下の論理ルールで複合判定を行います。
    - **在室判定 (OR):** いずれか1つのセンサーでも「人あり」を示していれば【在室】。
    - **不在判定 (AND):** すべてのセンサーが一定時間（例: 10分以上）「人なし」を示したときのみ【不在】（外出またはチェックアウト）と確定。

### ③ 画像付き自動通知機能の統合
- **目的:** ホストがリアルタイムでゲストの動向を把握できるようにする。
- **計画:** 
  - 在室状況の変化（不在 ➡ 在室 / 在室 ➡ 不在）が確定した瞬間に、LINE Notify や Discord Webhook を通じて、枠線で囲まれた証拠画像（detected_xxx.jpg）付きのメッセージをホストのスマートフォンに自動でプッシュ通知します。
