# YOLOトラッキングを用いたルールベース入退室判定の実装計画

動画内の人物のトラッキングデータ（YOLOのバウンディングボックス座標）から、民泊におけるゲストの「入室（entry）」「退出（exit）」を精度高く自動判定するルールベースアルゴリズムを構築します。

## 背景と分析結果

アノテーションデータとYOLOトラッキング座標を分析した結果、以下の傾向と課題が明らかになりました：

- **動きの傾向**: 
  - 画面の右端（$X > 1500$ 付近）が玄関扉の位置であり、ここから左方向へ移動する動きが「入室（entry）」、右方向へ移動して右端で消える動きが「退出（exit）」に該当します。
- **課題 (IDの断片化・入れ替わり)**:
  - YOLOのトラッキングIDが途中で切れて別IDになる（断片化）、あるいはノイズで座標が飛ぶなどの理由により、単純な「単一IDの開始・終了座標の比較」だけでは判定漏れや誤判定（Accuracy 78%程度）が発生します。
  - 同一の動画クリップ内で、複数の断片化したトラックを結合するか、あるいはクリップ全体の動きのトレンドを統合的に捉える必要があります。

---

## 提案する判定アルゴリズム

### 1. ドアゾーンと部屋ゾーンの定義
- **ドアゾーン (Door Zone)**: $X \ge 1500$ （玄関扉付近）
- **部屋ゾーン (Room Zone)**: $X \le 1400$ （民泊の室内）

### 2. トラックの簡易結合処理 (Stitching)
同じ動画クリップ内で、時間的・空間的に極めて近い2つのトラック（例: トラックAの終了座標とトラックBの開始座標の距離が小さく、フレームの間隔が短い）を同一人物の軌跡として結合します。これにより、ID切れによる判定漏れを防ぎます。

### 3. 入退室判定ルール (Rule-based Decision)
結合された（あるいは単一の）人物軌跡に対して、以下の優先順位でラベルを判定します：

1. **入室 (entry)**:
   - 軌跡の最初の数フレームが「ドアゾーン（$X \ge 1500$）」から始まり、最後の数フレームが「部屋ゾーン（$X \le 1400$）」に達しており、かつ全体の移動方向が左向き（$dx < 0$）であること。
2. **退出 (exit)**:
   - 軌跡の最初の数フレームが「部屋ゾーン（$X \le 1400$）」から始まり、最後の数フレームが「ドアゾーン（$X \ge 1500$）」で消失しており、かつ全体の移動方向が右向き（$dx > 0$）であること。
3. **その他 (passing_by)**:
   - 上記のいずれにも該当しない動き（室内のみでの移動、ドア付近だけの短時間の滞在など）。

- `evaluate_rules.py` を実行し、現在アノテーションされている `data/annotation_summary.csv` （約100件）をテストデータとして、適合率・再現率・F値が旧判定（78%）を超えることを確認します。
